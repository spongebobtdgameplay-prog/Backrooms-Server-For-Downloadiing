V0.3.20 removes the duplicate legacy gameplay HUD that was still rendering underneath the V3 HUD and causing stacked LEVEL 0 / RESTORE POWER / FPS text and visible flicker. Gameplay now has one HUD owner: the V3 overlay handles objective, real FPS, interaction prompt, and sprint, while the legacy HUD path is limited to temporary center status messages only. The old legacy stamina draw is no longer called, and the V3 sprint bar is moved two pixels upward so the 3px bar is vertically centered against the 9px SPRINT label.
