V0.3.18 makes the native menu actually mouse-driven instead of treating ENTER LEVEL 0 as decorative text. The main menu now has visible clickable ENTER LEVEL 0 / RESUME SESSION and NEW SESSION button surfaces with real hitboxes, hover fill, border emphasis, and sliding label/arrow animation; the pause menu gets matching clickable RESUME and MAIN MENU controls while keyboard shortcuts remain optional. Gameplay UI is separated from the menu typography path with a dedicated condensed HUD renderer, stronger shadows, dark objective/FPS panels, and a high-contrast interaction prompt so the interface no longer disappears into Level 0's yellow walls.
