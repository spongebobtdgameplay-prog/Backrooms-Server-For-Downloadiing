V0.3.22 fixes the laptop touchpad camera freeze while keyboard movement keys such as W are held. The Windows build now temporarily disables Precision Touchpad Accidental Activation Prevention by setting the current user AAPThreshold to maximum sensitivity only while gameplay mouse capture is active, while keeping SDL GameInput enabled. The exact previous AAPThreshold is restored when mouse capture ends or the game closes. On Windows SDKs that expose the touchpad SystemParametersInfo API, the game also applies and restores the documented most-sensitive touchpad mode. No administrator permission is required and no global keyboard hook or background key capture is used.
