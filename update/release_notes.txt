V0.3.15 removes the failed near-black CSS imitation from active use and restores the older visible Backrooms menu treatment: centered dark panel, readable title/description, clear filled yellow bordered buttons, and mouse hover. ENTER LEVEL 0, RESUME SESSION, NEW SESSION, RESUME, and MAIN MENU are now real clickable buttons instead of being presented as keyboard-bind text. The main and pause screens share one layout definition so the drawn buttons and click hitboxes cannot drift apart. Keyboard shortcuts remain optional fallbacks, but the UI no longer depends on them.
