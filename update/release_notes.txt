V0.3.12 stops hand-guessing the native menu layout. The original browser style.css is now stored with the native project and converted into GeneratedWebUi.h by tools/convert_web_ui.py during GitHub/developer builds. The main menu uses the original CSS box model: clamp/vw/vh positioning, exact title size and line-height, paragraph max-width and line-height, measured native glyph height and width for safe wrapping, original button dimensions, footer/top-row spacing, mobile breakpoint values, colors, stripes, noise, and title highlight. This fixes THE LOBBY overlapping the paragraph and makes future web UI changes flow through the converter instead of being manually retyped.
